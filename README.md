# Stream Master Hub

Você conhece o painel Sigma?

O painel office que gerenciar lista m3u?

Onde essas listas são transformadas em conexões para os usuários se conectar 



Exemplo eu importo lista x no painel Apartir do painel já com a lista importada vai analisar a lista , vai exibir no dashbord a quantidade de canais, de filmes de séries 



Vou poder criar usuários ou testes para os clientes se conectar em aplicativos player  através da DNS personalizada que não vai ser mais da lista mais sim do painel 

Posso ver os onlines, os testes expirados a quantidade de usuários no dashbord 



Vai te a aba categoria de Canais , filmes e séries onde é possível ver o conteúdo exemplo capa, a URL podendo editar apagar 



Aba do conteúdo exibir 

Tudo organizado baseado na lista, pelas categorias q vem da lista 



Um painel completo gerenciador de IPTV 



Que gerencia tudo quando se tem a lista ok importada no sistema 



Podendo criar várias conexões (usuários)
